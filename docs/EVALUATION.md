## Verified positive controls

- The application uses NexusInterface `secureApiCall` for reviewed mutations; NexGo does not directly collect wallet PINs, profile passwords, API Basic credentials, or sessions.
- Current core invoice payment builds DEBIT and CLAIM in one transaction and rejects already-paid, cancelled, and wrong-token payment attempts.
- Historical 2026-09-30 evidence at the same exact head records a clean `npm ci --offline --ignore-scripts` and successful production Webpack build; this was not freshly rerun on 2026-10-02.
- The supplied baseline equals HEAD and the 2026-10-02 review reverified runtime source hashes against that historical evidence; the untracked `vision.md` remained review context only.
- Pinned session source confirms NexusInterface, not NexGo, owns active-session injection and PIN collection. This is a valid secret boundary, but current code does not consume the available readiness state.

These controls do not close the active issues. A green build alone is not payment or package acceptance.
